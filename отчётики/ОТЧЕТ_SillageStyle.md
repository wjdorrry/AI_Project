# Отчёт по проекту «Sillage&Style»

**Дисциплина:** экспертные системы  
**Тип работы:** веб-приложение (одностраничное, без серверной части)  
**Дата:** апрель 2026 г.

---

## 1. Цель проекта

Разработать прототип **экспертной системы**, которая по признакам стиля одежды (теги: цвета, стиль) подбирает **парфюмерное семейство** (цитрус, древесные, восточные и т.д.), опираясь не на субъективное «угадать», а на **заданную матрицу весов** (−10…+10), согласованную с методическими материалами (файл `PerfumeStyleMatrix.xlsx`).

---

## 2. Что сделано

### 2.1. База знаний

- Исходная матрица из таблицы Excel перенесена в машиночитаемый формат **JSON** (`data/perfumeStyleMatrix.json` в корне курса и копия в `sillage-style/src/data/perfumeStyleMatrix.json`).
- В матрице: **12 тегов** (9 цветов: Black, White, Grey, Beige, Blue, Brown, Green, Red, Pink; 3 стиля: Sportswear, Evening, Streetwear) и **11 парфюмерных семейств** (Citrus, Aquatic, Green, Fruity, Woody, Musk, Powdery, Gourmand, Oriental, Floral, Leather).
- Для повторного обновления базы после правок Excel добавлен скрипт **`scripts/export_matrix_to_json.py`** (Python, библиотека `openpyxl`).

### 2.2. Механизм вывода (экспертная логика)

- Реализована функция **`computeScores`** (`sillage-style/src/utils/scoreFamilies.js`):
  - на вход подаётся матрица, список активных тегов и множество **исключённых** семейств;
  - для каждого семейства **суммируются** веса по всем выбранным тегам;
  - **победитель** определяется только среди семейств, **не** попавших в исключения (**hard constraints**): даже при высокой сумме по одежде исключённое семейство в рекомендацию не попадает.

### 2.3. Пользовательский интерфейс (без бэкенда)

Собрано веб-приложение на **React** в папке **`sillage-style/`**:

| Компонент | Назначение |
|-----------|------------|
| **ImageUploader** | Загрузка до 3 фотографий, превью в браузере (данные на сервер не отправляются). |
| **TagPicker** | Выбор тегов образа вручную (имитация ответа системы компьютерного зрения до подключения реального API). |
| **PreferenceToggle** | Переключатели вида «Без …» для каждого семейства — жёсткие ограничения. |
| **ResultDisplay** | Карточка результата: рекомендуемое семейство (русское название и краткое описание), итоговый балл, список исключённых семейств, визуализация топа по сумме весов. |

Дополнительно: файл **`familyCopy.js`** — русскоязычные подписи и текстовые описания семейств для отчёта пользователю.

## 3. Использованные технологии и инструменты

| Категория | Инструмент / технология |
|-----------|-------------------------|
| Языки | **JavaScript** (логика и интерфейс), **Python** (разовый экспорт из Excel) |

**Зависимости npm (основные):** `react`, `react-dom`, `@vitejs/plugin-react`, `vite`.

---

## 4. Ограничения текущей версии

- Нет подключения к **API компьютерного зрения** (Hugging Face, Google Vision и т.п.): теги вводятся вручную для демонстрации цепочки «признаки → правила → вывод».
- Нет серверной части: вся экспертная логика выполняется **в браузере**.
- Объём матрицы соответствует предоставленному файлу Excel (12×11), а не условным «25 тегов × 6 семейств» из чернового ТЗ — при расширении таблицы достаточно обновить JSON (через скрипт или вручную).

---

## 5. Как запустить проект (для проверки)

```text
cd sillage-style
npm install
npm run dev
```

Открыть в браузере адрес, указанный в консоли (часто `http://localhost:5173`).

---

## 6. Выводы

В рамках работы реализованы ключевые элементы **экспертной системы**: формализованная **база знаний** (матрица весов), **механизм логического вывода** (суммирование и выбор максимума с учётом **жёстких ограничений**), а также **объясняющий интерфейс** (описание семейства и сравнение баллов). Веб-часть демонстрирует применение дисциплинарных идей в виде работающего прототипа без необходимости разворачивать сервер.
